# Passo a Passo

완전 초보를 위한 브라질 포르투갈어(PT-BR) 학습 웹앱. 단일 `index.html`, iPhone·iPad 대응.

- 0단원 발음 규칙·구어 줄임말 14개 + 1~17단원(대학 생활·교환학생 포함), 단어 458개 · 문장 303개 (브라질 일상 구어체)
- 간격 반복(SRS) 단어 학습: 뒤집는 단어 카드 → 퀴즈(뜻 고르기 / 단어 고르기 / 듣고 고르기)
- 동사 17개 현재형·과거형 활용표 + 퀴즈
- 문법 규칙 39개: 문법 탭 + 각 단원 화면 (표·예문·주의점)
- 생활 단어 200개: 대학생 기준 주제 10개(캠퍼스·과제·자취·학식·돈/알바·SNS·약속·교통·감정·슬랭), 전체 단어 검색, 주제별 연습
- 내 단어장: 단어·문장 직접 추가(한 줄씩 여러 개 붙여넣기 가능), 수정·삭제, 오늘의 학습에 먼저 출제, 검색·백업 포함
- 기록: 연속 학습일, 14일 학습량, 단원별 진도, 설정(한글 발음 표시·말하기 속도·하루 새 단어 수)
- 발음은 기기 음성(pt-BR) 사용, 진도는 기기에 저장 (기기 간 이동은 기록 탭의 백업 코드)
- 포르투갈어는 타자기체(IBM Plex Mono Light) 고정, 한글은 기본·연필·펜 또는 직접 올린 폰트(ttf·otf·woff·woff2) 중 선택

## 아이폰 홈 화면에 추가

1. 저장소 Settings → Pages → Source: **Deploy from a branch**, Branch: `claude/charming-ride-0ffioi` / `(root)` → Save
2. 아이폰 Safari로 `https://hysdllover.github.io/portugues/` 열기
3. 공유 버튼 → **홈 화면에 추가** → 추가

- 홈 화면 앱은 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다.
- 업데이트는 자동입니다. 앱을 열거나 다시 화면으로 돌아올 때 새 버전(`version.json`)을 확인해 스스로 새로고침합니다(퀴즈 중에는 끝난 뒤). 홈 화면 아이콘 그림만은 iOS 정책상 다시 추가해야 바뀝니다.
- 기록은 그 기기의 앱 안에 저장됩니다. 다른 기기로 옮길 때는 기록 탭 → 기록 옮기기(백업 코드)를 쓰세요.

## 파일 구조

- `src/app.html` — 앱 본문
- `tools/build.py` — `src/app.html`로 홈 화면용 `index.html`, `version.json`을 만들고 `sw.js` 캐시 버전을 올립니다: `python3 tools/build.py`
- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` — GitHub Pages로 배포되는 홈 화면 앱
